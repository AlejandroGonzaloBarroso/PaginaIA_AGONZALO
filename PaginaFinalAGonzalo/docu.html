Resumen Técnico

El sistema implementa una arquitectura Hub-and-Spoke donde Supabase actúa como el núcleo central de datos.

  • Frontend: PWA en GitHub Pages (Zero-Config deploy).
  • Mobile: Contenedor nativo Android (Cordova v13) con WebView optimizado.
  • Backend: Lógica de servidor desacoplada en Worker Python (Lubuntu VM).

Pipeline CI/CD

Flujo de automatización en GitHub Actions.

1. Git Push

El desarrollador sube cambios a la rama main.

2. Build Environment

GitHub levanta contenedor Ubuntu con Java 17 y Node 18.

3. Cordova Compilation

npm install cordova
cordova platform add android@13.0.0
cordova build android --release

4. Artifact Ready

El archivo .apk se publica automáticamente para descarga.
